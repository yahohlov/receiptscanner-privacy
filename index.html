Політика конфіденційності застосунку «Розумний Чек»

Дата останнього оновлення: 11 вересня 2026 р.

Ця політика пояснює, які дані збирає застосунок «Розумний Чек» (пакет com.yaroslav.receiptscanner), як вони використовуються та зберігаються.

Хто обробляє дані

Застосунок розробляється й підтримується однією особою (незалежний розробник). Ми не продаємо й не передаємо ваші дані рекламодавцям чи будь-яким третім сторонам, окрім сервісів Google, необхідних для роботи функцій застосунку (описано нижче).

Які дані збираються та навіщо

Фотографії чеків

  • Застосунок використовує камеру пристрою для фотографування товарних чеків.
  • За замовчуванням розпізнавання тексту відбувається повністю локально на пристрої (офлайн-рушій Tesseract), без надсилання фото кудись іще.
  • Якщо ви вмикаєте перемикач «Хмарне розпізнавання» в налаштуваннях, фотографія чека надсилається до Google Gemini API для точнішого розпізнавання тексту. Це відбувається лише за вашою явною дією (увімкнений перемикач) і лише в момент сканування. Застосунок не зберігає копії фото на власних серверах — серверів розробника, що зберігають дані користувачів, не існує.

Обліковий запис Google

  • Для входу в застосунок використовується Google Sign-In. Застосунок отримує базову інформацію облікового запису (email, ідентифікатор), потрібну для автентифікації.
  • Вхід не є обов'язковим для базового сканування чеків — потрібен лише для резервного копіювання/синхронізації.

Резервні копії та синхронізація

  • Якщо ви увійшли через Google-акаунт, застосунок може зберігати резервну копію ваших даних (список товарів, історія покупок, налаштування) у вашому власному Google Drive.
  • Ці дані зберігаються у вашому Google Drive, до якого розробник не має доступу. Ви можете видалити резервну копію у будь-який момент через власний Google Drive.

Дані, що зберігаються локально на пристрої

  • Історія покупок, розпізнані товари, категорії, магазини, налаштування нагадувань — усе це зберігається локально в базі даних застосунку на вашому пристрої.
  • Ці дані захищені стандартним шифруванням сховища Android (File-Based Encryption) і не покидають пристрій, окрім випадків, описаних вище (хмарне розпізнавання, резервне копіювання).

Кому передаються дані

Застосунок не використовує рекламні мережі, аналітичні SDK чи сервіси відстеження третіх сторін. Дані передаються лише сервісам Google, і лише для функцій, які ви самі вмикаєте:

  • Google Gemini API — фото чека, лише якщо ввімкнено «Хмарне розпізнавання», лише в момент сканування.
  • Google Drive API — резервна копія даних, лише якщо ви увійшли в обліковий запис Google.
  • Google Sign-In / Credential Manager — для автентифікації.

Видалення даних

Ви можете видалити всі локальні дані, видаливши застосунок з пристрою. Резервну копію в Google Drive можна видалити окремо через ваш Google Drive або звернувшись за контактом нижче.

Діти
